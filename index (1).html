Cài Đặt Chế Độ WebApp Native Toàn Màn Hình

Giao diện này đã tự động ẩn khung điện thoại khi mở trên iPhone thật. Bạn chỉ cần mở trang này bằng Safari trên máy vợ -> nhấn nút Chia sẻ (Share) -> chọn "Thêm vào MH chính" (Add to Home Screen). App mở toàn màn hình sang trọng như App Store và không bao giờ bị văng hay thu hồi chứng chỉ.

Cách 2 • Xuất File .IPA Thật Để Tự Ký Capacitor + Xcode Cloud Build
  1. Bấm nút "1. Tải file index.html" bên dưới (hệ thống sẽ tự động tắt khung giả lập để xuất bản full-screen chuẩn iPhone).
  2. Đưa file index.html lên GitHub cùng file cấu hình .github/workflows/build-ipa.yml bên dưới.
  3. Vào mục Actions trên GitHub để tải file LEclatStudio-Unsigned.ipa về ký bằng ESign, Feather, Sideloadly hoặc TrollStore!
name: Build L'Eclat Studio iOS IPA
on:
  push:
    branches: [ main, master ]
  workflow_dispatch:

jobs:
  build-ipa:
    runs-on: macos-latest
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20

      - name: Build Native iOS Wrapper via Capacitor
        run: |
          mkdir -p www
          cp index.html www/index.html
          npm init -y
          npm install @capacitor/core @capacitor/cli @capacitor/ios
          npx cap init "LEclat Studio" "com.leclat.makeupnail" --web-dir=www
          npx cap add ios

      - name: Compile Unsigned iOS App Bundle
        run: |
          cd ios/App
          xcodebuild -project App.xcodeproj \
            -scheme App \
            -configuration Release \
            -sdk iphoneos \
            -derivedDataPath build \
            CODE_SIGN_IDENTITY="" \
            CODE_SIGNING_REQUIRED=NO \
            CODE_SIGNING_ALLOWED=NO \
            clean build

      - name: Package into Unsigned .IPA
        run: |
          mkdir -p Payload
          cp -r ios/App/build/Build/Products/Release-iphoneos/App.app Payload/
          zip -r LEclatStudio-Unsigned.ipa Payload

      - name: Upload .IPA Artifact
        uses: actions/upload-artifact@v4
        with:
          name: LEclatStudio-Unsigned-IPA
          path: LEclatStudio-Unsigned.ipa
Đã tải file index.html chuẩn Native iOS!
